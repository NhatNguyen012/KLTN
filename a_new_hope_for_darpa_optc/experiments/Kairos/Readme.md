# Kairos


This repository contains the implementation of the approach proposed in the paper "KAIROS: Practical Intrusion Detection and Investigation using Whole-system Provenance". Available [here](https://arxiv.org/pdf/2308.05034).

```
@inproceedings{cheng2024kairos,
  title={KAIROS: Practical Intrusion Detection and Investigation using Whole-system Provenance},
  author={Cheng, Zijun and Lv, Qiujian and Liang, Jinyuan and Wang, Yang and Sun, Degang and Pasquier, Thomas and Han, Xueyuan},
  booktitle={2024 IEEE Symposium on Security and Privacy (SP)},
  year={2024},
  organization={IEEE}
}
```

Implementation is available on [github](https://github.com/ubc-provenance/kairos/).
The commit cloned is [0e0b633beb46a1117c0a6d63be5d2481b59ac0dc](https://github.com/ubc-provenance/kairos/commit/0e0b633beb46a1117c0a6d63be5d2481b59ac0dc).

The optc_models.pt model is pre-trained models provided by the authors on this [GoogleDrive](https://drive.google.com/drive/u/0/folders/1YAKoO3G32xlYrCs4BuATt1h_hBvvEB6C).

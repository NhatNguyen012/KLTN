# A New Hope For DARPA OpTC


This repository contains experiments related to the paper "A New Hope for DARPA OpTC". 
These experiments involve three approaches:

- "[PyGOD](https://jmlr.org/papers/v25/23-0963.html): A Python Library for Graph Outlier Detection".
- "[FLASH](https://www.computer.org/csdl/proceedings-article/sp/2024/313000a139/1Ub23WQw20U): A Comprehensive Approach to Intrusion Detection via Provenance Graph Representation Learning".
- "[KAIROS](https://arxiv.org/pdf/2308.05034): Practical Intrusion Detection and Investigation using Whole-system Provenance".
